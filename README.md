# Tosin Ojo Personal Portfolio

This is a polished static portfolio website for Tosin Ojo, built from the supplied 2026 resume. It presents cloud engineering experience, inferred case-study style projects, technical skills, certifications, experience, and contact information.

## Files

- `index.html` - the one-page portfolio.
- `styles.css` - all layout, responsive styling, visual project artwork, and motion.
- `script.js` - mobile navigation, project filtering, scroll reveals, and stat counters.
- `assets/hero-cloud-command-center.png` - generated hero image used by the first screen.
- `assets/tosin-ojo-resume.pdf` - downloadable resume PDF.

## Preview Locally

Open `index.html` in a browser. No install step, package manager, or build tool is required.

## Deploy

This site can be deployed as a static site on GitHub Pages, Netlify, Vercel, Azure Static Web Apps, AWS Amplify, or S3 static hosting. Upload the full folder and keep the `assets` directory beside `index.html`.

## Customize

Update contact details, project descriptions, or resume file paths directly in `index.html`. The project filters are controlled by each card's `data-category` values and the filter buttons in the Projects section.
